# Contributing

1. Create a focused branch from `main`.
2. For behavior changes, add or update unit tests first.
3. Keep domain logic independent of Android framework APIs.
4. Run `gradle testDebugUnitTest` and `gradle assembleDebug`.
5. Open a pull request with scope, rationale, tests and screenshots when UI changes.

Do not commit API keys, signing keys, personal data, browser credentials, model weights, or generated build outputs.

All contributions must preserve the project's user-review and platform-compliance boundaries.
